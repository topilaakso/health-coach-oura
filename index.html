Health Coach

A personal, read-only application for regularly downloading my own Oura sleep, readiness, activity, heart-rate and workout data to my laptop and evaluating trends over time.

Intended data flow

After account authorization, the application is intended to retrieve records from the Oura API, save them as JSON files in a private data/oura/ folder on my Mac, and produce local reports for reviewing sleep, recovery and training trends. It requests only the daily, heartrate and workout permissions.

A weekly refresh on Sunday is planned. Account connection, scheduled downloads and report generation have not yet been enabled.

This site contains application information only. It does not receive Oura credentials or health records. The integration is independent of Oura and is intended only for its owner's account.
